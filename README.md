# Подготовка к экзаменам (магистратура)

Статический сайт для GitHub Pages: билеты в режимах «Вопрос-ответ» и «Тест».

- `index.html` — главная с разделами (массив `SECTIONS`)
- `exam.html` — список дисциплин и тренажёр (`exam.html?d=<имя>`)
- `data/subjects.js` — список дисциплин
- `data/<имя>.js` — вопросы и ответы дисциплины

Добавить дисциплину: создать `data/<имя>.js` по образцу и дописать имя в `data/subjects.js`.
